Quiz Flow

Part 1 is the honest inventory of every part we have. Part 2 (the flow design) is the next step. Verified 18 Aug 2026 against the code and real composed quizzes — not from memory.

1 Answer mechanics

How a single question is played.

Live

  • LivePlain MC — one question, four short options, one answer, a re-teach.
  • LiveTeach-back — explain in your own words; LLM-graded on verdict + depth. 1 slot every run.
  • LiveConfidence wager (steady) — pick, then "How sure?" Sure / Think so / Guessing → Lock it in. This is the scheduling signal — it gates ledger promotion (§5), not just logged.
  • LiveReversed (Wed speed mutator) — prompt states the ANSWER, options are candidate QUESTIONS. Fact slots only; calculations stay standard recall.
  • LiveBattleground formats (Friday-only, all 4-option) — spot-the-lie / true-false / sum-as-MC / MC, varied across the four zones.

Approved — built & specced, not yet integrated

  • ApprovedSwipe Sort — flick a statement into one of two labelled buckets.
  • ApprovedNumeric — type the answer; calculator on method Qs, plain pad on mental (scoped + logged).
  • ApprovedOrdering — drag scrambled tiles into sequence (live reflow).
  • ApprovedShort-text — type a word or two; fuzzy matcher forgives typos/variants.

Dormant · built then reverted (code inert)

  • DormantStandard-run format variety, hidden in-app ×2, encore, old interactive ordering, teach-back three-lights, old typed inputs.

Parked

  • ParkedTap-the-diagram — a content-sourcing bet, not a shell build.

3 In-quiz tools & systems

Features within a run.

  • Heats — Heat 1 = speed round, Heat 2 = steady round, then the teach-back.
  • Timer — speed round only (fuse + countdown, red under 6s; timeout = miss).
  • Combo — speed round; ×N with a bonus at ≥2.
  • Skip — "it'll come back around"; on a fresh topic, "I'll check when your class gets there."
  • Re-teach — the "why" shown on every question.
  • XP / scoring; Blitz double-XP at the family weekly-tally layer (never in-app).
  • Achievements / badges — Sure Shot, Clean Run, Blitz Master/PB, etc.
  • Territory bar / % claimed — Battleground only.

4 Planner intelligence

What picks the questions — generation-side, but it shapes the run.

  • Subject balance — every core subject guaranteed, capped per run.
  • Repair — weakest topics first.
  • Throwback (LAW 3) — one aged-mastered topic in every run (continuous, not an event).
  • Fresh — current class topics from the weekly Canvas sweep.
  • Answer-length gate (LAW 1) — bans the "tap the longest option" tell.
  • Format bank (LAW 2) — see the flagged discrepancy below.

5 The ledger / IP

The state under everything.

  • Two axes, independent — confidence → scheduling (when to re-test); depth → reporting (what parents see). Solid is reached only by a confident, calm, spaced confirm.
  • Promotion logic (state_writer.py): Sure + correct → can move toward solid (calm + spaced) · Think so + correct → developing at most, never straight to solid · Guessing / lucky / trivially-fast correct → untested, no promotion · any wrong / lucky / trivial-correct → resets a REPAIR topic's confirms to 0.
  • Deterministic code owns all scheduling + state; the LLM only does language.
  • Curriculum taxonomy — maps messy Canvas content onto stable, masterable topics (the moat).

6 Rules & laws

The constraints everything obeys.

  • Fair judging — numeric equivalence (0.75 = ¾), fuzzy text; a right answer is never failed on a technicality.
  • Spelling & punctuation are coaching-only — never demote mastery.
  • Confidence is the scheduling signal — the one player input that gates promotion.
  • Calculator use is logged — calc-assisted correct is never counted as mental mastery.
  • Evidence weight — a swipe (50/50) is weak; MC is medium; typed / numeric / ordering are strong.
  • No negation framing in the fast rounds — spot-the-lie is Friday-only.
  • Short, fast-to-READ speed questions — no walls of text, no puzzles in the timed round.
  • Reordering must be real drag (Pointer Events, live slide) — never tap-to-order or HTML5 drag.
  • Process — one mechanic at a time → isolated playable prototype → approved for fun AND quality → only then integrated.
  • Parent comms — silence is the only "not done" signal; transparency law on the kid wrap.
  • SEASONS laws 1–5 — answer-length gate · format bank · throwback continuous · runtime≠target · new input types deferred (now being done as the approved mechanics).
