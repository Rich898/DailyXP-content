# XP Daily

A daily learning **game** that closes the gap between how a kid is actually doing at school day to day
and what their parent knows.

Game mechanics earn daily play → the daily play generates real evidence of understanding → that
evidence becomes visibility parents have never had, day to day and week to week. It is **not** a plain
multiple-choice quiz, and never was.

**Start here:**

- **`VISION.md`** — the problem we're solving and why (the north star).
- **`CURRENT-STATE.md`** — what the quiz actually is today (authoritative).
- **`modes/MECHANICS.md`** — the gameplay-mechanics toolbox, and the process for adding new ones.
- **`UNDERSTANDING.md`** / **`LEDGER-RULES.md`** — the confidence + depth ledger (the IP).
- **`RUNBOOK.md`**, **`SEASONS.md`**, **`REPORTING.md`**, **`CONTENT-MODEL.md`** — operations, rhythm,
  parent reporting, and curriculum model.

Two repos: this one (public — code + quiz shells) and **`DailyXP-private`** (ledgers, targets, state).
